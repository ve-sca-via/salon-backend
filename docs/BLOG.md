# Blog & SEO

A client-managed blog, built in-house (no headless CMS). Its job is to win
*informational* searches ("bridal makeup cost in Delhi") and **link into `/salons` and
`/products`** — articles that don't link to the money pages don't move SEO.

The admin side is **gated by the `blog` feature flag** — see
[FEATURE_FLAGS.md](FEATURE_FLAGS.md). The public read endpoints are not gated.

## Data model — `blog_posts`

Migrations: `20260820000000_create_blog_posts_table.sql`, `20260904000000_add_blog_post_faqs.sql`.

| Column | Notes |
|---|---|
| `slug` | unique URL segment |
| `title`, `excerpt`, `content` | `content` is HTML, **sanitised server-side with `nh3`** before storage |
| `cover_image_url`, `cover_image_alt` | Cloudinary; alt required when a cover is set |
| `meta_title` (≤ 70), `meta_description` (≤ 160), `focus_keyword` | fall back to `title` / `excerpt` |
| `tags` | `text[]`, GIN-indexed |
| `faqs` | `jsonb`, default `[]` — structured Q&A rendered as a collapsible section **and** emitted as `FAQPage` JSON-LD |
| `status` | `draft` / `published` / `scheduled`; `published_at` drives sort and the scheduled gate |
| `reading_minutes` | computed on save |

RLS: public read only where `status = 'published' AND published_at <= now()`; writes are admin-only.

## Endpoints (`/api/v1/blog`)

| Method | Path | Auth |
|---|---|---|
| GET | `/blog` | public — paginated published list, tag/search filters |
| GET | `/blog/tags` | public |
| GET | `/blog/sitemap-data` | public — slug + `updated_at` for the sitemap |
| GET | `/blog/{slug}` | public — **declared last** so it doesn't swallow the static paths |
| GET | `/blog/admin/all`, `/blog/admin/{post_id}` | admin + `blog` flag |
| POST | `/blog` | admin + `blog` flag |
| PUT / DELETE | `/blog/{post_id}` | admin + `blog` flag (delete is soft) |

Cover images go through the existing Cloudinary upload in `app/api/upload.py`.

## Where it lives

| Surface | Files |
|---|---|
| Backend | `app/api/blog.py`, `app/services/blog_service.py`, `app/schemas/{request,response}/blog.py` |
| Admin panel | `salon-admin-panel/src/pages/Blog.jsx`, `BlogEditor.jsx` |
| Web (server-rendered) | `salon_management_next/src/app/(public)/blog/` — `page.tsx` (index) and `[slug]/page.tsx` (post, `generateMetadata`, JSON-LD); `src/app/sitemap.ts` includes posts |

## Handing it to the client

They supply: a keyword per planned article, the copy, images with alt text, and the byline.
Agree the internal-linking rule (every article links to salons/products) before they write.
To switch it on for them, flip the `blog` flag — see FEATURE_FLAGS.md → *Selling a feature*.

## Not built (deliberately)

Comments, reactions, newsletter capture, multi-author roles, categories beyond flat tags.
