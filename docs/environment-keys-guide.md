# Backend environment variables

**Source of truth:** `app/core/config.py` (Pydantic `Settings`). Template: `.env.example`.
Keys **without** a default below are required — the app refuses to start without them.

Some runtime values deliberately live in the database instead (Razorpay keys, fees,
version policy) so an admin can change them without a redeploy — see
[system_config.md](system_config.md).

## Application & server — all required

| Key | Meaning |
|---|---|
| `APP_NAME`, `APP_VERSION`, `APP_DESCRIPTION` | FastAPI metadata |
| `ENVIRONMENT` | `development` / `staging` / `production`. `development` routes email to Mailpit and unlocks dev-only endpoints |
| `DEBUG` | bool |
| `API_PREFIX` | `/api/v1` |
| `HOST`, `PORT`, `WORKERS` | uvicorn bind |
| `TOKEN_CLEANUP_INTERVAL_SECONDS`, `BACKGROUND_SHUTDOWN_TIMEOUT_SECONDS` | background task timing |
| `ALLOWED_ORIGINS` | comma-separated CORS allowlist — add every frontend origin |
| `ALLOWED_HOSTS` | comma-separated `TrustedHostMiddleware` list |
| `LOG_LEVEL`, `LOG_FILE` | logging (see [OBSERVABILITY.md](OBSERVABILITY.md)) |

## Supabase & auth — all required

| Key | Meaning |
|---|---|
| `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY` | project credentials |
| `DATABASE_URL` | Postgres connection string |
| `JWT_SECRET_KEY`, `JWT_ALGORITHM` | app JWT signing |
| `ACCESS_TOKEN_EXPIRE_MINUTES`, `REFRESH_TOKEN_EXPIRE_DAYS` | token lifetimes |

## Payments

| Key | Default | Meaning |
|---|---|---|
| `RAZORPAY_KEY_ID`, `RAZORPAY_KEY_SECRET` | required | **Fallback only** — the product-order flow uses them when `system_config` has no keys. Bookings and vendor registration read `system_config` **only**. |

## Email

| Key | Default | Meaning |
|---|---|---|
| `EMAIL_FROM`, `EMAIL_FROM_NAME` | required | sender; domain must be verified in Resend (`lubist.com`) |
| `ADMIN_EMAIL` | required | inbox for career applications, join requests, partner leads |
| `SUPPORT_EMAIL` | `support@lubist.com` | the "contact us" address shown to users |
| `RESEND_API_KEY` | `""` | blank = sends no-op with a warning |
| `MAILPIT_SMTP_HOST`, `MAILPIT_SMTP_PORT` | `127.0.0.1`, `54325` | in `development`, all mail goes here instead of Resend |

Supabase Auth emails (signup confirmation, password reset) are a **separate channel**
configured in the Supabase dashboard — see [RESEND_EMAIL_SETUP.md](RESEND_EMAIL_SETUP.md).

## Frontend URLs — all required

| Key | Used for |
|---|---|
| `FRONTEND_URL` | links in customer emails (`https://www.lubist.com`) |
| `VENDOR_PORTAL_URL` | vendor email links — **must keep its `/vendor` path**; `email.py` derives the login URL from it |
| `RM_PORTAL_URL` | RM links |
| `ADMIN_PANEL_URL` | admin links |

## OTP (MessageCentral)

| Key | Default | Meaning |
|---|---|---|
| `MESSAGECENTRAL_CUSTOMER_ID` | required | |
| `MESSAGECENTRAL_AUTH_TOKEN` | `""` | **preferred** long-lived token from the dashboard |
| `MESSAGECENTRAL_KEY`, `MESSAGECENTRAL_EMAIL` | `""` | legacy token-generation fallback, used only without `AUTH_TOKEN` |
| `MESSAGECENTRAL_BASE_URL` | `""` | |
| `MESSAGECENTRAL_DEFAULT_COUNTRY_CODE`, `MESSAGECENTRAL_OTP_LENGTH`, `MESSAGECENTRAL_OTP_EXPIRY_SECONDS` | required | phone auth is India-only by design |
| `OTP_DEV_MODE` | `false` | outside production: OTPs are printed to the log instead of sent |

## Cloudinary — all required

`CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET`,
`CAREER_CLOUDINARY_UPLOAD_TYPE` (`private`/`public`), `CAREER_CLOUDINARY_SIGNED_URL_TTL` (seconds).

## Client apps — all default off

`ENFORCE_PARTNER_APP_FOR_VENDORS`, `ENFORCE_PARTNER_APP_ROLES`,
`REQUIRE_CLIENT_APP_HEADER_FOR_VENDORS` (bool, `false`) and `CLIENT_POLICY_CACHE_SECONDS` (`60`).
Each flag can be overridden at runtime by a lower-case `system_config` row. Semantics and
rollout order: [CLIENT_APPS_AND_VERSIONING.md](CLIENT_APPS_AND_VERSIONING.md).

## Script-only (not read by the app)

`BETTERSTACK_SQL_USER`, `BETTERSTACK_SQL_PASSWORD`, `BETTERSTACK_SQL_ENDPOINT` —
`scripts/betterstack_query.py`.

Never commit real values. Secrets live in `.env` locally and in the platform's secret
store (DigitalOcean for prod, Railway for staging).
