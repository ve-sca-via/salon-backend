# Backend local setup

FastAPI + Supabase (Postgres, Auth). All docs: [docs/DOCS_HUB.md](docs/DOCS_HUB.md).

## Prerequisites

- Python **3.11** (`runtime.txt`), a venv at `.venv`
- Docker Desktop **running** — without it the local Supabase containers are down and every
  DB-backed endpoint answers a bare 500
- Supabase CLI (CI pins **2.118.0**)

## First run

```powershell
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env.local        # fill in — see docs/environment-keys-guide.md
supabase start                      # local Postgres + Auth + Mailpit; applies every migration
.\run-local.ps1                     # menu: backend / admin panel / Next web / tests
```

- API: http://localhost:8000 · Swagger: http://localhost:8000/docs
- Local email lands in **Mailpit** (`supabase start` prints the URL), never a real inbox.
- Phone OTPs: set `OTP_DEV_MODE=true` and read the code from the server log.
- Run uvicorn **without `--reload`** while scripts hammer it — an edit mid-request can hang
  the reloader on Windows.

## Test data

```powershell
python scripts/seed_service_categories.py   # once per fresh DB
python scripts/seed_web_test_accounts.py    # web.*@example.com / Test@1234, every role
python scripts/seed_regular_buyer.py        # a fully activated B2B buyer
```

`seed_web_test_accounts.py` expects an admin and an RM account to exist already. Login is
rate-limited to **5/minute** per IP — pace scripted sign-ins.

## Tests

```powershell
.venv\Scripts\python -m pytest -m "not integration"   # fast suite, no stack needed
.venv\Scripts\python -m pytest -m integration         # needs `supabase start`
```

Staging end-to-end flows: [docs/E2E_TESTING.md](docs/E2E_TESTING.md).

## Deploying

`dev` → PR into `staging` (Railway) → PR into `main` (DigitalOcean, prod). The git remote is
**`ve-sca-via`**, not `origin`. Schema changes: [docs/MIGRATION_SAFETY.md](docs/MIGRATION_SAFETY.md).
